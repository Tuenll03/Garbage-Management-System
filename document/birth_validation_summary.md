# สรุปภาพรวมและอธิบายระบบตรวจสอบวันเกิด (Birth Date Validation Summary)

เอกสารฉบับนี้จัดทำขึ้นเพื่ออธิบายหลักการทำ **Auto-formatting (จัดรูปแบบขณะพิมพ์)** และ **Validation (การตรวจสอบเงื่อนไข)** สำหรับช่องกรอกวันเดือนปีเกิด (`birth`) ในไฟล์ Register.jsx ให้เข้าใจง่ายและเห็นภาพการทำงานทีละขั้นตอนครับ

---

## 📌 1. ความต้องการของระบบ (Requirements)
ระบบต้องการให้ช่องกรอกวันเกิดตรวจสอบข้อมูล ดังนี้:
1. **ต้องไม่เป็นค่าว่าง** (Required Field)
2. **ต้องอยู่ในรูปแบบที่กำหนด:** `วว-ดด-ปปปป` (เช่น `14-05-2564` ใช้ปี พ.ศ. ของไทย)
3. **ต้องเป็นวันที่ในอดีต** (ไม่ใช่วันนี้ หรือ วันในอนาคต)
4. **ผู้สมัครต้องมีอายุตั้งแต่ 20 ปี และไม่เกิน 100 ปี**

---

## 🛠️ 2. กลไกการจัดรูปแบบขณะพิมพ์ (Auto-Formatting)
เราประยุกต์หลักการมาจากช่องกรอก Citizen ID โดยสร้างตัวกรองช่วยพิมพ์เมื่อเกิด Event `onChange`:

```javascript
const formatBirth = (value) => {
  const clean = value.replace(/\D/g, '').substring(0, 8); // 1. กรองเอาเฉพาะตัวเลขยาวไม่เกิน 8 ตัว
  let parts = [];
  if (clean.length > 0) parts.push(clean.substring(0, 2));  // 2. แยก 2 ตัวแรกเป็น "วัน"
  if (clean.length > 2) parts.push(clean.substring(2, 4));  // 3. แยก 2 ตัวถัดมาเป็น "เดือน"
  if (clean.length > 4) parts.push(clean.substring(4, 8));  // 4. แยก 4 ตัวหลังเป็น "ปี"
  return parts.join('-');                                   // 5. นำมาต่อกันด้วยเครื่องหมาย "-"
};
```

## 🔍 3. การตรวจสอบรูปแบบและความถูกต้อง (Regex & Calendar Checking)
เกิดขึ้นเมื่อผู้ใช้กดปุ่ม **Register (Submit)** เพื่อตรวจว่าข้อมูลมีรูปแบบที่ถูกต้องและมีตัวตนจริงบนปฏิทินโลก

### 3.1 การแกะข้อมูลด้วย Regex
```javascript
const birthPattern = /^(\d{2})-(\d{2})-(\d{4})$/;
const match = birth.match(birthPattern);
```
ใช้เพื่อตรวจสอบและดึงส่วนของข้อมูลออกมา:
*   `match[1]` = วัน (Day)
*   `match[2]` = เดือน (Month)
*   `match[3]` = ปี พ.ศ. (Year BE)

### 3.2 การแปลงปี พ.ศ. เป็น ค.ศ.
```javascript
const yearCE = yearBE - 543;
```
เนื่องจากภาษา JavaScript (`new Date`) ไม่เข้าใจระบบปฏิทิน พ.ศ. เราจึงต้องนำปี พ.ศ. ที่ได้มา **ลบด้วย 543** เพื่อเปลี่ยนให้เป็น ค.ศ. ก่อนนำไปเข้าฟังก์ชันของ JavaScript

### 3.3 ตรวจสอบวันที่มีอยู่จริง (เพื่อดักวันที่ผิด เช่น 31 กุมภาพันธ์)
```javascript
const birthDate = new Date(yearCE, month - 1, day);
if (
  birthDate.getFullYear() !== yearCE ||
  birthDate.getMonth() !== month - 1 ||
  birthDate.getDate() !== day
) {
  setMessage("วันเดือนปีเกิดไม่ถูกต้อง");
  return;
}
```
**ทำไมต้องตรวจสอบซ้ำหลังจากตั้งค่าแล้ว?**
เพราะ JavaScript มีนิสัยชอบปรับข้อมูลให้อัตโนมัติ (Auto-Adjustment) เมื่อเราป้อนวันเกิดที่ไม่มีจริง เช่น วันที่ **31 กุมภาพันธ์ 2021** มันจะไม่แจ้ง Error แต่จะทบเศษวันให้กลายเป็นวันที่ **3 มีนาคม 2021** ทันที 

เราจึงต้องเขียนเงื่อนไขตรวจสอบว่า *วันที่ที่ JavaScript สร้างขึ้นมาจริงๆ นั้น ตรงกับค่าเดิมที่เราป้อนเข้าไปตอนแรกหรือไม่* หากไม่ตรงกัน แสดงว่าผู้ใช้กรอกวันที่ที่ไม่มีจริงเข้ามา

## 📅 4. การคำนวณอายุและตรวจสอบขอบเขต (Age Logic & Boundaries)
ตรวจสอบว่าผู้สมัครมีอายุจริงในช่วง **20 - 100 ปี** หรือไม่

### 4.1 สูตรคำนวณอายุจริงระดับวัน-เดือน
```javascript
let age = today.getFullYear() - birthDate.getFullYear();
const m = today.getMonth() - birthDate.getMonth();
if (m < 0 || (m === 0 && today.getDate() < birthDate.getDate())) {
  age--;
}
```
*   **เปรียบเทียบปี:** เริ่มจากการลบปีเฉยๆ เช่น `2026 - 2006 = 20`
*   **ตรวจสอบวันครบรอบวันเกิด:** 
    *   ถ้ายังไม่ถึงเดือนเกิด (`m < 0`) หรือ อยู่เดือนเดียวกันแต่ยังไม่ถึงวันที่เกิด (`m === 0` และ วันนี้ < วันเกิด)
    *   ระบบจะทำการ **ลบอายุออก 1 ปี** (`age--`) ทันที เนื่องจากปีนี้ผู้สมัครยังไม่ครบรอบวันเกิดของตนเอง ทำให้ได้อายุจริงที่แม่นยำ

### 4.2 ตรวจสอบข้อจำกัดของช่วงอายุ
```javascript
if (age < 20) {
  setMessage("ผู้สมัครต้องมีอายุตั้งแต่ 20 ปีขึ้นไป");
  return;
}

if (age > 100) {
  setMessage("ผู้สมัครต้องมีอายุไม่เกิน 100 ปี");
  return;
}
```
เมื่อคำนวณอายุจริงแบบละเอียดเรียบร้อยแล้ว ระบบจะเช็กขอบเขต หากอายุต่ำกว่า 20 ปี หรือมากกว่า 100 ปี จะแสดงข้อความเตือนและปฏิเสธการยืนยันข้อมูลทันที
